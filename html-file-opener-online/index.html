What is an HTML File?

HTML stands for HyperText Markup Language. It is the standard language used to create and structure web pages on the internet. An HTML file contains text, hyperlinks, and references to images and CSS (Cascading Style Sheets) that tell a web browser exactly how to display a webpage.
