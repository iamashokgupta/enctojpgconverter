Understanding File Formats: PPT vs. PPTX vs. PDF

Format Description Best Used For
PPT The legacy binary file format used by Microsoft PowerPoint 97-2003. Opening presentations on very old, legacy computer systems.
PPTX The modern, XML-based format introduced in Office 2007. It supports rich media and advanced animations. Creating, editing, and actively presenting slideshows on a projector.
PDF Portable Document Format. A "digital printout" that flattens all layers into a static document. Emailing, sharing, printing, and archiving finalized presentations securely.

Troubleshooting: What Happens to Animations?
